Welcome

This panel turns the messy, community-sourced perk tables into clean, validated JSON databases for celestial.decaded.dev.

Sources are served exactly as they are. CSV Chaos Tamer only reformats. It never edits, deduplicates, or "corrects" the source data. If you spot any problems with the sources, please report them to the original source maintainers.

Quick start

  1. Add your files in the browser. On the Source metadata tab, click Add source and upload that source’s CSV/Markdown files (drag-and-drop works too). The panel creates the source and stores its files for you.
  2. Run a dry build first. On the Build tab, leave "Write NyaDB datasets" unchecked and run the build. The console streams every step, and validation problems surface before anything is written.
  3. Write the databases. Re-run with "Write NyaDB datasets" checked. Output lands in the NyaDB/ folder.
  4. Inspect the output. Use the Datasets tab to view the generated JSON (read-only), and the Keyword filter tab to tune mature auto-marking.

The tabs

Only one build can run at a time. While this panel or a CLI build holds the lock, other builds wait. Close the panel with Ctrl+C in the console (where you ran this panel from) to release it.
